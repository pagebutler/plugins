# PB codes: the site contract

The rules every site keeps, which `pb check` and every deploy check. A finding names its rule's code and variant, its place, and a `hint:` line that names the fix: follow it. An error stops a deploy and no preview is made; fix every error, then check again. The template layer's PB-T codes: `references/template-codes.md`. What to tell the person about a few of these: `references/telling-the-person.md`.

<!--pb:generated site-rules-->
- **PB-01 `static-files`**: A site is static files plus the template layer: every served URL maps to a file or a template output, and there is no server code. Variants: `server-folder`, `functions-folder`, `server-file`, `api-scripts`, `project-files`.
- **PB-02 `complete-pages`**: Every page is a complete `.html` document with its content at rest: no SPA shell, no `200.html`, no catch-all rewrite. Variants: `mount-node`, `framework-shell`, `fallback-page`, `catch-all`, `missing-routes`, `script-shell`.
- **PB-03 `additive-scripts`**: Scripts are additive: a page reads correctly with JavaScript off. Variants: none.
- **PB-04 `real-links`**: Navigation uses real links, not a client-side router. Variants: `hash-links`.
- **PB-05 `template-layer`**: Editable content uses the template layer; an unknown `data-pb-*` attribute is an error naming the substitute. Variants: none.
- **PB-06 `title-and-description`**: Every served page has a `<title>` and a `<meta name="description">`, in the page or its head partial. Variants: `missing-title`, `missing-description`, `missing-both`.
- **PB-07 `pagebutler-script`**: Pagebutler adds marked regions and a same-origin script under `/_pb/`; a Content-Security-Policy that blocks same-origin scripts gets a warning. Variants: `meta`, `header`.
- **PB-08 `redirects-and-headers`**: Redirects and headers live in `_redirects` and `_headers`, in Cloudflare's grammar and within its limits. Variants: `target-missing`, `too-many-fields`, `conditions`, `status`, `status-forced`, `status-not-found`, `absolute-source`, `domain-source`, `target-http`, `target-scheme`, `rewrite-offsite`, `loop`, `too-many-static`, `too-many-dynamic`, `too-many-dynamic-plain`, `source-query`, `duplicate-source`, `rewrite-query`, `header-outside-rule`, `header-no-colon`, `header-empty-name`, `header-empty-value`, `header-name`, `header-value`, `header-value-ascii`, `set-cookie`, `clear-site-data`, `framing-header`, `header-path`, `empty-rule`, `too-many-header-rules`, `too-many-headers`, `duplicate-path`, `hsts`, `platform-header`, `frame-ancestors`, `two-splats`, `splat-name`, `host-splat`, `captures`, `placeholder-twice`, `placeholder-prefix`, `unknown-placeholder`, `line-length`, `file-size`, `rules-size`, `more`, `more-warnings`.
- **PB-09 `page-files`**: `404.html` is the not-found page, and one address has one page file: never `about.html` beside `about/index.html`, no folder named `index`, and no file beside a folder of its own name. Variants: `both`, `index-folder`, `file-and-folder`, `not-found-missing`, `no-not-found-page`.
- **PB-10 `forms`**: Forms post to `/_pb/forms/<name>`, and the name is declared under `forms` in `pb.config.json`. Variants: `undeclared-near`, `undeclared-name-rules`, `undeclared`, `sends-later`, `server-form`.
- **PB-11 `immutable-files`**: Files named by their content are kept by browsers for a year; a page never is, so an `immutablePatterns` entry may not match one. Variants: `matches-page`, `detected-file`, `detected`.
- **PB-12 `limits`**: Files, as uploaded and once baked, the file count, the site size, and each HTML file's nesting, elements and attributes stay within the limits, and the parser reads each HTML file to its end; the numbers are configuration. Variants: `file-size`, `file-count`, `site-size`, `baked-size`, `open-elements`, `elements`, `attributes`, `unreadable`, `time`, `memory`.
- **PB-13 `served-types`**: Served files have types from Pagebutler's table: no archives, programs or compressed copies, no file without an extension unless its name is a known one, such as `LICENSE`, and HTML in UTF-8. Variants: `unknown-type`, `refused-type`, `compressed`, `no-extension`, `not-utf8`, `declared-charset`.
- **PB-14 `preview-links`**: No absolute links to staging or deployment hosts; use root-relative paths. Variants: `link`, `links`, `canonical`, `absolute-url`.
- **PB-15 `underscore-paths`**: Pagebutler's own underscore paths (`_partials/`, `_content/`, `_`-prefixed `.html`, the control files) are never served, and other underscore folders are assets; an unreferenced `_`-prefixed `.html` is an error, and `_content/` is never uploaded. Variants: `unreferenced-template`, `content-file`, `content-folder`.
- **PB-16 `reserved-pb-prefix`**: `/_pb/*` is reserved: no file, redirect source, 200 rule's target or header rule may use it, and no file named `_pb` sits at the site root. Variants: `file`, `rule`, `root-file`.
- **PB-17 `collection-paths`**: A served `.html` at a collection, archive or pagination output path needs `data-pb-entry` for that path, except the folder an archive's or a paginated list's pages sit in. Variants: `entry`, `archive`, `pagination`.
- **PB-18 `generator-output`**: Generator output gets a warning before an import and a refusal after it. Variants: `detected`, `detected-working-directory`, `detected-manifest`, `imported`.
- **PB-19 `manifest-schema`**: `pb.config.json`, when present, validates against its schema. Variants: `unknown-key-near`, `unknown-key-elsewhere`, `unknown-key-top`, `unknown-key-file`, `unknown-key-none`, `wrong-type`, `missing`, `enum-nearest`, `enum`, `pattern`, `range`, `empty`, `name-rules`, `site-name`, `unusable-key`, `duplicate-key`, `syntax`, `more`, `vocabulary-version`.
- **PB-20 `dotfiles`**: Nothing whose path has a name starting with `.` is served, except `.well-known/` at the site root; `.htaccess` gets a warning; `.env` files, private keys and `.git` folders refuse the upload. Variants: `htaccess`, `htaccess-rule`, `htaccess-rules`, `dotfile`, `dotfiles`, `secret-file`, `git-folder`.
- **PB-21 `head-partial-metadata`**: A head partial carrying a `<title>` or `<meta name="description">` gets a warning. Variants: `title`, `description`.
- **PB-22 `archive-entries`**: An archive holds only files, each under one name that follows the upload path rule: no links, devices or other special entries, and no name twice. Variants: `link`, `hard-link`, `special`, `outside`, `backslash`, `backslashes`, `name`, `encoding`, `duplicate`, `duplicate-nfc`, `pbignore-size`, `pbignore-work`.
- **PB-23 `left-out-references`**: A page doesn't point into a folder every version leaves out: `node_modules/`, `_content/`, `.pb/` or `__MACOSX/`. Variants: `reference`, `references`.

## Files that aren't the site
- `.pbignore` in the site's folder lists the files `pb deploy` leaves out, one a line, as `.gitignore` does for git: they stay in the folder and never reach Pagebutler. Pagebutler never reads `.gitignore` for this, since a build's output is often in it.
- A site moving from another host often keeps files beside it that aren't the site, such as an `.htaccess`, deploy scripts, a `README.md`, tests or tools, which that host's deploy may still need. Each finding for one names its exact `.pbignore` line, and PB-01 `project-files` lists them all: add the line, and never delete or move the file. A finding for a file in a folder `project-files` names gives that folder's line too: add it only when the whole folder isn't part of the site, since a build's output folder often is the site.
- `pb deploy` leaves out what looks like secrets by itself, such as `.env`, `deploy.env`, `.htpasswd`, private keys and their backups, and says so in a `note:`; no `.pbignore` line can bring one back.
- A Keynote deck (`.key`) is left out as if it were a private key, so a page's link to one breaks: export it as a `.pdf` and link to that.
