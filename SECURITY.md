# Report a security problem

Report it privately, not in a public issue.

- On GitHub: [Report a vulnerability](https://github.com/pagebutler/plugins/security/advisories/new)
- By email: [hello@pagebutler.ai](mailto:hello@pagebutler.ai)

Say what you found, how to reproduce it and which version you use. `claude plugin list` shows the plugin's version. Leave out passwords, keys and other people's data.

This covers the plugin, the `pb` command and Pagebutler's own service.

To report a website hosted on butler.page, write to the same address.
